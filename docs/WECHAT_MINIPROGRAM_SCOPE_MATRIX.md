## 阶段验收门槛

### Phase 1 门槛

- 小程序启动不出现关键 JS 报错
- 登录、首页、个人中心、钱包可返回真实数据
- 所有主导航无死链

### Phase 2 门槛

- 下单到订单详情链路可闭环
- 发布账号后可在首页检索到

### Phase 3 门槛

- 充值与余额变化可验
- 提现申请与记录可验
